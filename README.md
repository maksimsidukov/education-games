# Лапки

Пять развивающих мини-игр для детей от трёх лет. В каждом раунде есть голосовое задание на русском, которое можно повторить. Приложение хранит настройки звука на устройстве и после первой загрузки работает офлайн.

## Локальный запуск

Запустите из корня репозитория `python -m http.server 8000` и откройте [localhost:8000](http://localhost:8000/). Для проверки игровой логики выполните `node --test`.

## GitHub Pages

В настройках репозитория в разделе **Pages** выберите **Deploy from a branch**, ветку **main** и папку **/(root)**. Все пути относительные, поэтому приложение работает в подпапке репозитория.

При изменении файлов приложения обновляйте версию кэша в `sw.js`. Новая версия начнёт работать после закрытия всех открытых вкладок приложения и повторного открытия.
